# Staged Migration Plan: DeviceProtocol + DeviceIdentity Abstraction

## Target End-State

### 1. Java DeviceProtocol Interface (Core Abstraction)
```java
// org/openfit/app/protocol/DeviceProtocol.java
public interface DeviceProtocol {
    /**
     * Discover and validate required characteristics after onServicesDiscovered.
     * Returns the characteristics to enable notify on; throws ProtocolException if setup fails.
     * Does NOT enqueue notify; caller is responsible for calling enqueueNotify() on returned chars.
     */
    Map<String, BluetoothGattCharacteristic> setup(BluetoothGatt gatt)
        throws ProtocolException;
    
    /**
     * Initialize the protocol session post-MTU negotiation.
     * Called exactly once per connect. For protocols without MTU negotiation, called with default MTU 23.
     */
    void start(int mtu);
    
    /**
     * Route an inbound characteristic change (UUID + raw value).
     * Protocol internally dispatches to its session methods.
     */
    void onCharacteristicChanged(UUID uuid, byte[] value);
    
    /**
     * Clean teardown on disconnect. Idempotent.
     */
    void teardown();
    
    /**
     * Unified listener shape across all protocols.
     * Note: HuamiSession.onAuthSuccess/onAuthFailed are translated to onReady/onError;
     * Fetch callbacks (onFetchSample, onFetchDone) are Huami-specific and optional for other protocols.
     */
    interface Listener {
        void onReady();
        void onError(String reason);
        void onHeartRate(int bpm);
        void onLog(String msg);
        // Optional callbacks (default no-ops, Huami uses these)
        default void onFetchSample(String kind, double value, long ts) { }
        default void onFetchDone(boolean ok) { }
    }
    
    void setListener(Listener l);
}
```

### 2. Java ProtocolRegistry (Service Locator)
```java
// org/openfit/app/protocol/ProtocolRegistry.java
public final class ProtocolRegistry {
    private static final Map<String, Class<? extends DeviceProtocol>> protocols =
        new LinkedHashMap<>();
    
    static {
        register("standard", StandardHrProtocol.class);
        register("huami", HuamiProtocol.class);
        register("garmin", GarminProtocol.class);
    }
    
    public static void register(String id, Class<? extends DeviceProtocol> cls) {
        protocols.put(id, cls);
    }
    
    /**
     * Detect protocol from advertised services (AUDIT.md #6).
     * Check proprietary services FIRST (Huami/Garmin) before standard HR,
     * since both proprietary devices also advertise 0x180D (standard HR service).
     * Returns "garmin", "huami", "standard", or null if unrecognized.
     */
    public static String detectFromServices(List<UUID> services) {
        for (UUID svc : services) {
            // Proprietary services checked first
            if (HUAMI_CHUNK_SERVICE.equals(svc)) return "huami";
            if (GARMIN_GFDI_SERVICE.equals(svc)) return "garmin";
        }
        // Only if no proprietary service found, check standard HR
        if (services.contains(HR_SERVICE)) return "standard";
        return null;
    }
    
    public static DeviceProtocol create(String id, String authKey, String btName, 
                                        Listener listener) throws ProtocolException {
        DeviceProtocol p = null;
        if ("huami".equals(id)) {
            p = new HuamiProtocol(authKey);
        } else if ("garmin".equals(id)) {
            p = new GarminProtocol(btName);
        } else if ("standard".equals(id)) {
            p = new StandardHrProtocol();
        } else {
            throw new IllegalArgumentException("unknown protocol: " + id);
        }
        p.setListener(listener);
        return p;
    }
}
```

### 3. TypeScript Device Capabilities & Protocol Registry
```typescript
// web/src/ble/protocols.ts
export type DeviceProtocolType = "standard" | "huami" | "garmin" | "polar" | "coros";

export interface DeviceCapabilities {
    supportsLiveHr: boolean;
    supportsActivity: boolean;
    supportsFetch: boolean;  // Huami, some Garmin
    requiresAuth: boolean;   // Huami, some others
    mtuRequired?: number;    // Huami: 517, Garmin: 515, Standard: 0
}

export const PROTOCOL_CAPS: Record<DeviceProtocolType, DeviceCapabilities> = {
    "standard": { supportsLiveHr: true, supportsActivity: false, supportsFetch: false, requiresAuth: false },
    "huami": { supportsLiveHr: true, supportsActivity: true, supportsFetch: true, requiresAuth: true, mtuRequired: 517 },
    "garmin": { supportsLiveHr: true, supportsActivity: true, supportsFetch: true, requiresAuth: false, mtuRequired: 515 },
    "polar": { supportsLiveHr: true, supportsActivity: false, supportsFetch: false, requiresAuth: false },
    "coros": { supportsLiveHr: true, supportsActivity: false, supportsFetch: false, requiresAuth: false },
};

// Service UUID → protocol inference. Proprietary services are listed first.
const PROTOCOL_SERVICES: Record<DeviceProtocolType, string[]> = {
    "huami": ["00000016-0000-3512-2118-0009af100700"],   // chunk write
    "garmin": ["6a4e2800-667b-11e3-949a-0800200c9a66"], // GFDI service
    "standard": ["0000180d-0000-1000-8000-00805f9b34fb"], // HR service (checked last!)
    "polar": ["0000180a-0000-1000-8000-00805f9b34fb"],   // device info (placeholder)
    "coros": ["0000180a-0000-1000-8000-00805f9b34fb"],   // placeholder
};

export function inferProtocol(services: string[]): { type: DeviceProtocolType; confidence: "high" | "medium" | "low" } {
    // Normalize to lowercase for comparison
    const svcLower = services.map(s => s.toLowerCase());
    
    // Check proprietary services FIRST (Huami, Garmin). Standard HR is checked last
    // because many proprietary devices also advertise 0x180D.
    for (const [proto, protos_services] of Object.entries(PROTOCOL_SERVICES)) {
        if (proto === "standard") continue; // Check standard HR last
        for (const svc of protos_services) {
            if (svcLower.includes(svc.toLowerCase())) {
                return { type: proto as DeviceProtocolType, confidence: "high" };
            }
        }
    }
    
    // Now check standard HR (only if no proprietary service was found)
    if (svcLower.includes("0000180d-0000-1000-8000-00805f9b34fb".toLowerCase())) {
        return { type: "standard", confidence: "medium" };
    }
    
    return { type: "standard", confidence: "medium" };  // Fallback default
}
```

### 4. Rust DeviceIdentity (Unified Device Key)

// crates/ofit-core/src/device_identity.rs (new file)
#[derive(Debug, Clone, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct DeviceIdentity {
    /// Protocol: "huami", "garmin", "coros", etc.
    pub device_type: String,
    /// Unique identifier: MAC address, serial number, or device-unique string.
    /// For live streams from BLE plugin: MAC address (from BluetoothDevice.getAddress()).
    /// For imports: extracted from file if available, else None (see Stage 5 caveats).
    pub device_unique_id: Option<String>,
    /// Optional model name for UI: "Forerunner 945", "Mi Band 7".
    pub device_model_name: Option<String>,
}

impl DeviceIdentity {
    /// Create fingerprint for deduplication: "type:id" (if id present) or just "type" (if id absent).
    pub fn fingerprint(&self) -> String {
        if let Some(id) = &self.device_unique_id {
            format!("{}:{}", self.device_type, id)
        } else {
            self.device_type.clone()
        }
    }
}

## After-Landing Walkthrough: Adding a New Device (~3 Files)

### Example: Add Coros Protocol

**File 1: Create Protocol Wrapper** (`org/openfit/app/protocol/CorosProtocol.java`)
```java
package org.openfit.app.protocol;

public class CorosProtocol implements DeviceProtocol {
    private CorosSession session;
    private Listener listener;
    
    @Override
    public Map<String, BluetoothGattCharacteristic> setup(BluetoothGatt gatt) 
        throws ProtocolException {
        BluetoothGattService svc = gatt.getService(COROS_SERVICE_UUID);
        if (svc == null) throw new ProtocolException("Coros service not found");
        
        BluetoothGattCharacteristic send = svc.getCharacteristic(COROS_SEND_CHAR);
        BluetoothGattCharacteristic recv = svc.getCharacteristic(COROS_RECV_CHAR);
        if (send == null || recv == null) throw new ProtocolException("Coros chars missing");
        
        return Map.of("send", send, "recv", recv);
    }
    
    @Override
    public void start(int mtu) {
        session = new CorosSession(mtu);
        session.setListener(new CorosSession.Listener() {
            @Override public void onHeartRate(int bpm) { listener.onHeartRate(bpm); }
            @Override public void onReady() { listener.onReady(); }
            @Override public void onLog(String msg) { listener.onLog(msg); }
        });
        session.start();
    }
    
    @Override
    public void onCharacteristicChanged(UUID uuid, byte[] value) {
        if (COROS_RECV_CHAR.equals(uuid) && session != null) {
            session.onNotify(value);
        }
    }
    
    @Override
    public void teardown() {
        if (session != null) {
            session.stop();
            session = null;
        }
    }
    
    @Override
    public void setListener(Listener l) {
        this.listener = l;
    }
}
```

## What NOT to Touch / Rollback Strategy

### Do NOT Modify

1. **GATT Operation Queue** (OpenFitBlePlugin.java, lines 639–640, 802–824):
   - Platform-imposed serialization of BLE operations
   - Protocols delegate through write callbacks; never touch queue directly

2. **Crypto & Auth Internals** (huami/crypto, garmin/GFDI):
   - Complex, tested, and fragile
   - Only wrap, don't refactor

3. **Existing Source Dedup Logic** (crates/ofit-core/src/dedup.rs):
   - Safe to extend with device_identity filtering; don't change preference algorithm

4. **MetricsSink Listener Shape** (RecordingService.java, lines 72–87):
   - Already extensible with default methods; don't break the contract

5. **BLE Bonding Flow** (OpenFitBlePlugin.java, lines 880–900):
   - Platform Android flow; protocols can't change it
   - Note: Garmin bonding is still in OpenFitBlePlugin.doConnect(), not delegated to protocol (by design)

### Rollback Strategy

Each stage is independently reversible:

- **Stage 0:** Delete new files + revert DB migration. Zero impact.
- **Stage 0.5:** Revert service extraction in onScanResult(); NativeScanResult services field is optional.
- **Stage 1:** Restore old setupHuami/startHuamiSession methods; delete HuamiProtocol. DeviceLink reverts to holding huami field.
- **Stage 2:** Restore old setupGarmin/startGarminSession; delete GarminProtocol.
- **Stage 3:** Revert UI changes back to name-regex heuristics.
- **Stage 4–7:** Revert DB migrations + handler changes; restore legacy feedHeartRate().

**Rollback likelihood:** Low if Stages 1–2 are tested on hardware.

## Conclusion

This plan delivers:

1. **DeviceProtocol abstraction** reducing per-protocol code from ~9 files to 3 (wrapper + session + registry entry).
2. **Service-based protocol inference** (Stage 0.5 + 3) replacing name regexes with advertised GATT services.
3. **Shared DeviceIdentity** (Stages 4–6) correlating live + imported data from the same device (by device_type + model_name, since MAC/serial are not universally available in exports).

**Stages 1–2 are on the critical path and require on-device hardware testing. All other stages are low-risk infrastructure changes.**
